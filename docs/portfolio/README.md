## First steps

1. Complete the brief and agree on the expected campaign-session workflow.
2. Write its requirements, rules and acceptance criteria.
3. Design and run tests against a recorded app version using fictional data.
4. Record findings, retest fixes and summarize the results.

Link each requirement to its tests and results. Keep intended behavior, observed
behavior and proposed changes clearly labeled.

Existing [automated-check instructions](../../ttrpg_tracker/app/README.md#verification)
and the [data guide](../data-and-backups.md) support this work.
