# Test records

**Status:** Planned.

## Test cases

For each case, record its ID, linked requirement or acceptance criterion,
preconditions, test data, steps and expected result.

## Execution results

Record the date, app version, environment, actual result, outcome and evidence
for each executed case. Identify blocked and unexecuted cases explicitly.

## Findings and retests

Record reproducible defects with expected and actual behavior, severity,
priority and evidence. Track requirement questions and improvement ideas as
separate findings. Add fix and retest references when available.

Maintain a small table linking requirements, cases, results and findings as
records are added.
